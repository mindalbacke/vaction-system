# 반차관리 휴가 도우미

인사정보에서 읽은 휴가 종류별 잔여량·사용량, 휴가 사용 기록, 반차 묶음 신청 상태는 선택한 직원의 개인 PIN을 확인한 뒤 반차관리 사이트의 Neon DB에 동기화됩니다. 인사정보 아이디와 비밀번호는 저장하거나 서버로 전송하지 않습니다.

사이트에서 등록한 반차는 도우미의 반차 목록으로 불러옵니다. 두 건을 선택해 묶은 다음 신청 기록에서 연차휴가·대휴 중 하나를 선택하면, 두 반차 중 빠른 날짜에 선택한 휴가 1일을 인사정보에 신청합니다. 휴가 사유는 빈칸으로 입력됩니다.

인사정보에 휴가 1일이 승인된 뒤에도 아직 지나지 않은 묶음 반차는 `반차 사용 기록`에서 다른 날짜로 변경할 수 있습니다. 승인된 인사정보 신청일은 그대로 유지되며, 변경 전·후 날짜와 변경 시각이 수정 내역에 남습니다. 이미 지난 반차는 수정할 수 없습니다.

직원 Chrome 안에서만 인사정보의 사용·잔여 휴가를 읽고, 반차 두 건을 휴가 1일 신청으로 입력해 주는 Manifest V3 확장 프로그램입니다.

## 개인정보 원칙

- 인사정보 아이디와 비밀번호는 저장하지 않습니다.
- 인사정보 잔여량과 신청 확인 기록은 `chrome.storage.local`에만 저장합니다.
- Cloudflare와 Neon에는 기존 반차 일정만 있으며 인사정보 잔여량은 전송하지 않습니다.
- 인사정보의 로그인·저장 버튼은 직원이 직접 누릅니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `chrome-extension` 폴더를 선택합니다.
5. 툴바에서 `반차관리 휴가 도우미`를 고정합니다.

## 사용 순서

1. 확장 프로그램에서 본인 이름과 반차관리 PIN을 입력하고 반차를 새로고침합니다.
2. `인사정보 열기`를 누르고 공식 로그인 화면에서 로그인합니다.
3. 인사정보 아이디와 비밀번호를 입력해 공식 로그인 화면을 채우고 로그인 버튼은 직접 누릅니다.
4. 휴가사용현황 화면을 열면 사용 휴가와 잔여 휴가를 자동으로 읽습니다. 필요하면 `사용·잔여 휴가 새로고침`을 누릅니다.
5. 반차 두 건을 골라 묶습니다. 서로 다른 날짜라면 더 빠른 날짜가 휴가 1일 신청일이 됩니다.
6. 파견휴가신청 화면을 연 뒤 `신청 화면 채우기`를 누릅니다.
7. 연차휴가·날짜·사유를 검토하고 인사정보의 `저장` 버튼을 직접 누릅니다.
8. 인사정보 신청 내역을 다시 열어 자동 확인하거나, GUI에서 `신청 확인됨`을 누릅니다.

## 반차관리 사이트 연결

확장 프로그램 0.3.2부터 반차관리 사이트의 `개인 휴가 잔여량`에서 `반차 도우미 열기`를 사용할 수 있습니다. 개인 PIN을 확인하면 공식 사용·잔여량, 미반영 반차, 참고 가능량과 신청 상태가 표시됩니다. 이 정보는 확장 프로그램에서 현재 페이지로만 전달되며 사이트 서버나 Neon DB에는 저장되지 않습니다.

0.3.1에서는 확장 프로그램을 업데이트하기 전에 열어 둔 인사정보 탭에도 새로고침 버튼을 누를 때 화면 인식 코드를 자동으로 연결합니다.

0.3.2에서는 로그인 탭을 새로 여는 순간 팝업이 닫혀 입력 작업이 중단되던 문제를 수정했습니다. 로그인 화면을 백그라운드에서 준비하고 아이디·비밀번호 입력이 끝난 뒤 탭을 표시합니다.

0.3.3에서는 안내·오류 문구를 화면 상단 대신 사용자가 누른 버튼 옆 말풍선으로 표시합니다. 인사정보시스템이 열려 있지 않아도 로그인 탭을 자동으로 만들고, 최대 15초 동안 실제 로딩 완료를 확인한 다음 입력합니다.

0.3.4에서는 `인사정보 열기`와 로그인 입력 기능이 `https://insa.mbc.co.kr/`를 직접 열도록 수정했습니다. 기존 탭을 찾을 때도 MBC 포털 등 다른 서브도메인을 인사정보 탭으로 잘못 선택하지 않습니다.

0.3.5부터 인사정보 휴가사용현황에서 연차휴가·대휴의 기본, 사용, 등록, 잔여량을 각각 표시합니다.

0.3.6에서는 반차 사용일·전반/후반·0.5일을 날짜별 기록으로 표시합니다. 인사정보 상세조회 표에서 확인되는 휴가 유형·시작일·종료일·사용 일수도 별도 기록으로 표시합니다.

0.3.7에서는 `사용·잔여 휴가 새로고침`이 인사정보의 조회 버튼을 먼저 실행하고 재로딩된 값을 다시 읽습니다. 결재 전 `등록` 수량도 예상 잔여량에서 반영하며, 반차 두 건은 날짜 입력 칸의 캘린더와 전반·후반 선택으로 묶을 수 있습니다.

0.3.8에서는 반차관리 사이트에서 휴가 1일 신청 내용을 최종 확인한 뒤, 확장 프로그램이 로그인된 Chrome 세션의 파견휴가신청 화면을 백그라운드에서 채우고 저장 버튼을 실행합니다. 인사정보 로그인 세션이 없거나 화면 구조를 찾지 못하면 저장하지 않고 오류를 반환합니다.

압축해제 방식으로 설치한 경우 소스가 업데이트된 뒤 `chrome://extensions`에서 `반차관리 휴가 도우미`의 새로고침 버튼을 눌러야 새 버전이 적용됩니다.

## 화면 인식 한계

인사정보시스템의 HTML 구조를 직접 확인하지 못한 상태에서 화면의 한글 라벨을 기준으로 입력칸을 찾습니다. 최초 설치 후 테스트 계정 또는 실제 제출 전 단계에서 반드시 입력 결과를 확인해야 합니다. 입력칸을 찾지 못하면 아무것도 제출하지 않고 오류만 표시합니다.
